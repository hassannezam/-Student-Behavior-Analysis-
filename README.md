# Student Behavior Analysis - SQL Queries

## 📌 Overview
This repository contains SQL queries for analyzing student behavior records from a school management system.

## 📊 Data Source
- **File**: HarSchoolRawData.csv
- **Database**: Microsoft SQL Server
- **Time Period**: 2 weeks of behavior tracking data

## 📂 Query Categories
### 1. Data Cleaning
-Data Cleaning Before Data Analysis
### 2. Student Overview (2 queries)
- Students with more than 20 behavior records
- Students with more than 20 records (with unique ID)

### 3. Staff Analysis (2 queries)
- Specific student's staff behavior records
- All students' staff behavior records

### 4. Behavior Patterns (3 queries)
- Specific student's behavior pattern by form group
- Comparison between two students
- Top 10 students behavior patterns

### 5. Daily Behavior (2 queries)
- Daily behavior frequency (>4 records)
- Daily behavior lowest frequency (<2 records)

### 6. Categorization (2 queries)
- Time-based behavior categorization
- Disciplinary categorization

## 🛠️ Requirements
- SQL Server 2012 or later
- Appropriate permissions to access the database tables

## 📝 Notes
- All queries are production-ready and tested
- Student names in queries are examples only
- Modify student names as needed for your analysis
